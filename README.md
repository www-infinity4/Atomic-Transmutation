# Atomic-Transmutation

## Diagnostic framing (safe, non-actionable)

When evaluating a resonance-style setup, treat it as a measurement problem first:

- Start by measuring **potential difference between the two bottles/electrodes** to establish baseline bias and stability over time.
- Then measure **field density in the air gap** with non-contact instrumentation to map where intensity peaks occur.

In short: use both measurements, but baseline with potential difference first, then correlate with field-density mapping.
