# Atomic-Transmutation

## Diagnostic framing (safe, non-actionable)

When evaluating a resonance-style setup, treat it as a measurement problem first:

- Start by measuring **potential difference between the two bottles/electrodes** to establish baseline bias and stability over time.
- Then measure **field density in the air gap** with non-contact instrumentation to map where intensity peaks occur.

In short: use both measurements, but baseline with potential difference first, then correlate with field-density mapping.

## Vein mapping interpretation

For mapping "cut-off streaks," include **physical directionality** as a primary data layer:

- Record vein strike/dip and termination points.
- Correlate direction trends with where signal proxies weaken or stop.

In short: yes—use where the veins are pointing, but validate direction data against measured field behavior rather than direction alone.

## Three-stage stack stability note

For a stacked Copper/Palladium/Silver setup, treat the copper plate as a **controlled receiver node**, not an unrestricted hot output:

- Prefer dampened, instrumented operation for repeatable readings.
- Use thermal/electrical limits and stability checks before increasing drive.

In short: default to dampening and control first; only increase output after stable characterization.
