Diagnostic Framework

Safety-bounded, measurement-first guidance for each stage of the apparatus.

🔌

Baseline Measurement

Start with potential difference between electrodes/bottles. Establish bias stability before attempting field-density scans.

📡

Field Density Mapping

Use non-contact instrumentation to map intensity peaks in the air gap. Correlate with the potential-difference baseline.

🗺️

Vein Directionality

Record strike / dip / termination points. Use physical direction as a primary layer, but validate against measured field behaviour.

🧊

Stack Stability (Cu node)

Default to dampened, instrumented operation on the copper plate. Increase drive only after stable characterisation.

🌀

7 / 8 / 9 Field Layers
